## Your monorepo isn't slow. Your runner is.

Watching builds creep toward ten minutes as your repo grows? Cached runs
that *still* take seconds? You didn't start writing slower code and your
tasks didn't get heavier — your task runner's per-task overhead did.

Here's the **same 3,270-task monorepo** (100 dependency layers), run three
ways on the same machine:

| | vx | Turborepo | Nx |
| --- | --- | --- | --- |
| **Cold build** (nothing cached) | **3m 48s** | 8m 18s | 8m 27s |
| **Cached**, nothing to rebuild | **0.55s** | 1.60s | 9.86s |
| **Cached**, restore outputs | **0.89s** | 2.00s | 10.44s |
| **Total CPU burned** | **23s** | 1,250s | 2,037s |

A cold build finishes in **under 4 minutes** where Turborepo and Nx take
**over 8**. A fully-cached run lands in **half a second** — not 1.6s, not
nearly 10s. Same tasks, same hardware.

And it's not a trick. For those 3,270 tasks vx spent **23 seconds of CPU**;
Turborepo spent **1,250**; Nx spent **2,037**. vx does roughly **50× less
work per task** — so the bigger and more complex your graph, the wider the
gap.

**vx doesn't compete on speed. Speed is the foundation it's built on** —
see the full [benchmarks](benchmarks/) (reproduce them yourself with
`bun bench/compare.ts`).

## Monorepo tooling shouldn't make you choose

**Turborepo** is simple but hits a ceiling — static JSON config, additive
restores that leak stale files, a cache that can't see your computed
inputs. **Nx** is powerful but heavy — a daemon, a plugin graph, codegen,
and a learning curve that never ends.

vx is the third option: **as simple as Turborepo, more capable than both,
and the fastest on the runs you do all day** — warm, cached builds. Your
config is real TypeScript. Your tasks are shell commands. There's no
daemon and no plugin protocol to learn. And it caches with correctness
guarantees the others don't offer.

## Sixty seconds to a cached build

```bash
bun add -d @vzn/vx
# …or grab the standalone binary (no Node or Bun required):
curl -fsSL https://raw.githubusercontent.com/vznjs/vx/main/install.sh | sh
```

```ts
// vx.config.ts — next to any package's package.json
import { defineProject } from '@vzn/vx'

export default defineProject({
  tasks: {
    build: {
      exec: { command: 'tsc -b' },
      dependsOn: ['^build'],
      cache: { inputs: { files: ['src/**'] }, outputs: { files: ['dist/**'] } },
    },
    test: {
      dependsOn: ['build'],
      exec: { command: 'bun test' },
      cache: { inputs: { files: ['src/**', 'tests/**'] }, outputs: { files: [] } },
    },
  },
})
```

```bash
vx run build                # this package + its dependency graph
vx run build test --all     # every package, one shared graph
vx run test --affected      # only what changed vs the base branch
vx run build                # again → replays from cache in milliseconds
```
