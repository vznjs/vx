## Monorepo tooling shouldn't make you choose

**Turborepo** is simple but hits a ceiling — static JSON config, additive
restores that leak stale files, a cache that can't see your computed
inputs. **Nx** is powerful but heavy — a daemon, a plugin graph, codegen,
and a learning curve that never ends.

vx is the third option: **as simple as Turborepo, more capable than both,
and the fastest on the runs you do all day** — warm, cached builds. Your
config is real TypeScript. Your tasks are shell commands. There's no
daemon and no plugin protocol to learn. And it caches with correctness
guarantees the others don't offer.

## Sixty seconds to a cached build

```bash
bun add -d @vzn/vx          # Bun ≥ 1.3; git required
```

```ts
// vx.config.ts — next to any package's package.json
import { defineProject } from '@vzn/vx'

export default defineProject({
  tasks: {
    build: {
      exec: { command: 'tsc -b' },
      dependsOn: ['^build'],
      cache: { inputs: { files: ['src/**'] }, outputs: { files: ['dist/**'] } },
    },
    test: {
      dependsOn: ['build'],
      exec: { command: 'bun test' },
      cache: { inputs: { files: ['src/**', 'tests/**'] }, outputs: { files: [] } },
    },
  },
})
```

```bash
vx run build                # this package + its dependency graph
vx run build test --all     # every package, one shared graph
vx run test --affected      # only what changed vs the base branch
vx run build                # again → replays from cache in milliseconds
```
