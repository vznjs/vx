## For years, you had two choices. Both cost you.

For mid-to-large monorepos, **Nx** was the only real answer — and you paid
the platform tax: a background daemon, a plugin graph, generators, a config
surface you *maintain* instead of ship. For small-to-mid, **Turborepo** was
the easy pick — until you hit the ceiling: static JSON config, additive
restores that leak stale files, a cache blind to your computed inputs.

Every team picks the tradeoff that hurts least and calls it a decision.
You've been a hostage to the lesser evil. There was never a third option.

## Now there is.

**vx** is the alternative that didn't exist — the power that pushed you to
Nx, the simplicity that drew you to Turbo, **faster than either**, and the
tradeoffs of neither. One self-contained binary. Config that's real
TypeScript. Shell is the API. No daemon, no plugins, no platform to serve —
just your tasks, cached and correct, replaying in **milliseconds**.

## Your monorepo isn't slow. Your runner is.

The same **3,270-task monorepo** (100 dependency layers), run three ways on
the same machine:

<div class="stat-table">

| | vx | Turborepo | Nx |
| --- | --- | --- | --- |
| **Cold build** | **3m 48s** | 8m 18s | 8m 27s |
| **Cached**, nothing to rebuild | **0.55s** | 1.60s | 9.86s |
| **Cached**, restore outputs | **0.89s** | 2.00s | 10.44s |
| **CPU burned** (same 3,270 tasks) | **23s** | 1,250s | 2,037s |

</div>

A cold build in **under 4 minutes** where the others take **over 8**. A
fully-cached check of 3,270 tasks in **half a second**. And the last row is
the foundation: for the *same work*, vx burns **~50× less CPU per task** —
so the bigger and more tangled your graph, the wider the gap grows.

**vx doesn't compete on speed. Speed is the foundation it's built on.**

## Sixty seconds to a cached build

```bash
bun add -d @vzn/vx
# …or grab the standalone binary (no Node or Bun required):
curl -fsSL https://raw.githubusercontent.com/vznjs/vx/main/install.sh | sh
```

```ts
// vx.config.ts — next to any package's package.json
import { defineProject } from '@vzn/vx'

export default defineProject({
  tasks: {
    build: {
      exec: { command: 'tsc -b' },
      dependsOn: ['^build'],
      cache: { inputs: { files: ['src/**'] }, outputs: { files: ['dist/**'] } },
    },
    test: {
      dependsOn: ['build'],
      exec: { command: 'bun test' },
      cache: { inputs: { files: ['src/**', 'tests/**'] }, outputs: { files: [] } },
    },
  },
})
```

```bash
vx run build                # this package + its dependency graph
vx run build test --all     # every package, one shared graph
vx run test --affected      # only what changed vs the base branch
vx run build                # again → replays from cache in milliseconds
```
