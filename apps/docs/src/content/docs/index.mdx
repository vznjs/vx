## Run less. Cache everything.

vx discovers your workspace projects, builds a task graph from declared
`dependsOn`, hashes inputs deterministically, and executes tasks in
topological order with maximum parallelism. Cache hits replay stored
outputs in milliseconds — with correctness guarantees the established
runners don't offer.

<CardGrid stagger>
  <Card title="Fastest warm paths" icon="rocket">
    A 100-project workspace runs fully cached in **144&nbsp;ms**. A
    1090-package, 100-layer graph (3270 tasks) replays in **0.62&nbsp;s**.
    At 15k input files, deriving every key costs zero file reads — hashes
    come straight from git's index.
  </Card>
  <Card title="Smarter caching" icon="approve-check">
    Resolved-config hashing means imports and computed values participate
    in cache identity. Declared outputs are wiped before exec **and**

    snapshot.
  </Card>
  <Card title="Deliberately simple" icon="setting">

  </Card>
  <Card title="Safe to trust" icon="seti:lock">
    HMAC artifact signing on the remote wire, corrupt-artifact validation
    that degrades to a miss, and SIGINT/SIGTERM reaping so no dev server
    is ever orphaned in CI.
  </Card>

## Adopt it in two minutes

```bash
bun add -d @vzn/vx          # Bun ≥ 1.3; git required
```

```ts
// vx.config.ts — next to any workspace package
import { defineProject } from '@vzn/vx'

export default defineProject({
  tasks: {
    build: {
      exec: { command: 'tsc -p .' },
      cache: {
        inputs: { files: ['src/**'] },
        outputs: { files: ['dist/**'] },
      },
    },
    test: {
      dependsOn: ['build'],
      exec: { command: 'bun test' },
      cache: { inputs: { files: ['src/**', 'tests/**'] }, outputs: { files: [] } },
    },
  },
})
```

```bash
vx run build                # current package (+ its dependency graph)
vx run build test --all     # every package, shared graph
vx run test --affected      # only what changed vs the base branch
vx watch dev                # re-run on file change
vx run build --dry          # predicted hits/misses, no execution
```
