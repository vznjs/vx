This page will define once, without reference to any one tool, each term
the Learn pages use: task graph, cache key, affected, hermeticity, remote
execution, seam and the rest, each with the name Turbo, Nx, Bazel and vx
give it. Every Learn page will link its terms here. It supports every
outcome the section aims at, and one most directly: after reading it you
should be able to compare tools by what they do rather than by what they
call it, which is what choosing a tool for stated reasons rests on.
