`app#build` joins `src/index.ts` and `banner.txt` into one file. Its inputs
list only `src/**`. You edit `banner.txt` and run the build.

## A forgotten input makes a wrong hit

<Diagram {...P.oldBanner} />

The key did not change, so vx handed back the old file. The run passed, and
the file is wrong. This is a
[stale hit](../../glossary/#cache-hit-miss-and-stale-hit).

A stale hit comes from something the task reads but the key never sees. It
can be a file, an environment variable, or a tool on your machine. A slow
run is easy to notice. A wrong result on a passing run is not.

## You list the inputs; vx never guesses

<Diagram {...P.listNotGuess} />

A guess can only see what one run happened to read. It also comes after the
run, too late to look anything up. So vx asks you for the list, and then
checks it.

## The sandbox turns a forgotten file into an error

<Diagram {...P.sandbox} />

The [sandbox](../../glossary/#hermeticity-and-sandboxing) runs the
task where only the files you listed exist. Reading `banner.txt` fails, and
the error names it. A failed task is never saved.

Step through the five runs: the edit, the stale hit, then the sandbox.

## In vx

Add `exec.sandbox` and grant the same files your inputs list.

```ts
import { defineProject } from '@vzn/vx'

export default defineProject({
  tasks: {
    build: {
      exec: {
        command: 'mkdir -p dist && cat src/index.ts banner.txt > dist/out.txt',
        sandbox: { allow: { read: ['src/**', 'banner.txt'], write: ['dist/'] } },
      },
      cache: {
        inputs: { files: ['src/**', 'banner.txt'] },
        outputs: { files: ['dist/**'] },
      },
    },
  },
})
```

<summary>How we know this is true</summary>

- [vx never guesses a task's input files](https://github.com/vznjs/vx/blob/main/packages/vx/tests/config.test.ts 'requires cache.inputs.files — the one declaration vx will not infer')

- [A failed sandboxed task is not saved](https://github.com/vznjs/vx/blob/main/packages/vx/tests/sandbox-runtime.unsafe.test.ts 'failed sandboxed task is NOT cached (re-runs next invocation)')
- [A run of hits never starts the sandbox](https://github.com/vznjs/vx/blob/main/packages/vx/tests/sandbox-runtime.unsafe.test.ts 'a run whose sandboxed tasks are all hits never starts the sandbox')
- [`node_modules` is readable without being listed](https://github.com/vznjs/vx/blob/main/packages/vx/tests/sandbox-runtime.unsafe.test.ts 'installed dependencies are readable without being declared inputs')
- [So is a linked package of your own](https://github.com/vznjs/vx/blob/main/packages/vx/tests/sandbox-request.test.ts 'a SCOPED link is found too: the scan descends one level into `@scope/`')
