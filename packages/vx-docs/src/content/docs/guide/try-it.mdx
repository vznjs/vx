## In vx

On your own repository, after the [quickstart](../../quickstart/) (or
[from Turborepo](../../migrate/from-turborepo/), or
[from Nx](../../migrate/from-nx/)), the same plan is one command:

```sh
vx run build test --dry
```

<details>
<summary>How we know this is true</summary>

- [`--dry` prints the plan without running it](../../cli/#planning-mode---dry---graph)
- [This planner and the `vx` command give every task the same key](https://github.com/vznjs/vx/blob/main/packages/vx/tests/playground-parity.unsafe.test.ts)
