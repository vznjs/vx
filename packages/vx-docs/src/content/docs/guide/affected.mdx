You fix a typo in the README and push. CI builds and tests everything.

Eight tasks ran for a file that no task reads. CI starts on a fresh

## Find the package each file belongs to

<Diagram {...P.owners} />

Git lists the files that changed since your branch started. Each file sits
in one package's folder, so it belongs to that package. The README sits in
no package folder.

## Add every package that uses it

<Diagram {...P.dependents} />

`app` uses `ui`, so a change to `ui` can break `app`. Add every package
that uses a changed package, directly or through another one. The result
is the [affected](../../glossary/#affected) set.

Pick a package below and see which tasks a change to it runs.

<GraphExplorer />

## Affected picks packages, the cache skips work

<Diagram {...P.considerThenRun} />

These are two different filters. The affected set works on whole packages,
before anything runs. The cache works on single tasks: it skips a task
when nothing the task reads has changed. Here, no task reads the README,
so nothing runs.

## A file no task declares is invisible

<Diagram {...P.invisible} />

This file sits in no package, so nothing is affected. No task declares it,
so no cache sees it either. The builds pass, and they never checked your
change. The fix is to declare the file as an input of the tasks that read
it.

## In vx

`--affected` runs your tasks only in the changed packages and the packages
that use them:

```sh
vx run build test --affected=origin/main
```

<details>
<summary>How we know this is true</summary>

- [The `--affected` flag and its base](../../cli/#--affectedbase)
- [A change selects its package and the ones that use it, never others](https://github.com/vznjs/vx/blob/main/packages/vx/tests/affected-dependents.test.ts)
- [A README-only change selects nothing and exits 0](https://github.com/vznjs/vx/blob/main/packages/vx/tests/affected-base-notes.test.ts)
- [A declared root file selects the packages that declare it](https://github.com/vznjs/vx/blob/main/packages/vx/tests/affected-workspace-files.test.ts)
- [A lockfile change selects every package](https://github.com/vznjs/vx/blob/main/packages/vx/tests/affected.test.ts)
- [Package links come from `package.json`](https://github.com/vznjs/vx/blob/main/packages/vx/tests/package-graph.test.ts)

</details>
