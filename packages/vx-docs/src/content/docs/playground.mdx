This is vx's own planner, running in your page on four small packages.

Edit a file, the environment or a config, press **Run**, and read which tasks
would run and why.

<Playground />

The planner plans: it runs no command and writes no file.

On your own repository, after the [quickstart](../quickstart/), the same plan
is one command:

```sh
vx run build test --all --dry
```
