import Diagram from '../../../components/guide/diagram/Diagram.astro'
import { lanes } from '../../../components/guide/diagram/diagram.js'

Every picture on the site is one component, `Diagram`, drawing one value
of `Picture`: boxes, arrows between them, notes and frames. It renders SVG
into the page when the site is built, so the picture is there with no
script, in both themes, and at any width. The data is documented in
`packages/vx-docs/src/components/guide/diagram/README.md`; this page renders
each part, and `packages/vx-docs/tests/diagram-kit.test.ts` reads what it
built.
