A Guide chapter draws its picture with these components. Each one renders
SVG into the page when the site is built, so the picture is there with no
script, in both themes, and at any width. Their props are documented in
`packages/vx-docs/src/components/guide/diagram/README.md`; this page renders
each of them, and `packages/vx-docs/tests/diagram-kit.test.ts` reads what it
built.
