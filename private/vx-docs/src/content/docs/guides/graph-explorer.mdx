Browse your task graph: what each task waits on, what waits on it, and why.

```sh
vx run build --all --dry=json > plan.json
```

Drop `plan.json` below, or paste it, then type a task. Click any task in a list to move to it. The plan stays in your browser: nothing is uploaded.
